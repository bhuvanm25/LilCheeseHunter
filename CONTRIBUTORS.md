Welcome to the TreatQuest project! This file tracks all team members and their GitHub usernames for project collaboration.

## How to Add Yourself

1. **Fork this repository**
2. **Add your information** to the table below
3. **Create a pull request** with your changes

**OR**

Create a [new issue](https://github.com/bhuvanm25/treatquest/issues/new?template=github-username.md) using the GitHub Username template.

## Instructions for Project Lead

Once usernames are collected, add contributors using:
```bash
# Add collaborators to the repository
gh repo invite <username> --repo bhuvanm25/treatquest
```

Or through GitHub web interface:
1. Go to repository Settings → Collaborators and teams
2. Click "Add people"
3. Enter the GitHub username
4. Select appropriate permissions
